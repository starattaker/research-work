# Alveolar Bone Loss Replication (Severity Only)

Replication of *AI-assisted radiographic analysis in detecting alveolar bone-loss severity and patterns* (Scientific Reports, 2026) using the **DenPAR** dataset — **through bone loss severity only** (no segmentation / pattern classification).

## Setup

```powershell
cd c:\Oralvis_Seekright
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
```

## Data

- Raw: `data/DenPAR/Dataset/` (Training / Validation / Testing)
- Processed: `data/processed/` (generated by preprocessing)

### Preprocess

```powershell
.\venv\Scripts\python.exe -m src.preprocess.prepare_dataset
.\venv\Scripts\python.exe scripts\validate_preprocessed.py
```

Creates:
- `data/processed/yolo_detection/` — YOLO tooth boxes (single/double root)
- `data/processed/keypoints/{cej,intersection,apex}/` — Keypoint R-CNN annotations

## Training (requires explicit approval before running)

### 1. Tooth detection (YOLOv8x)

Paper targets (test): precision 0.892, mAP50 0.963, mAP50:95 0.907

```powershell
.\venv\Scripts\python.exe scripts\train_detection.py
```

### 2. Keypoint detection (3× Keypoint R-CNN)

Paper targets (test AP50:95 OKS): CEJ 0.954, intersection 0.912, apex 0.815

```powershell
.\venv\Scripts\python.exe scripts\train_keypoints.py
```

Or individually:

```powershell
.\venv\Scripts\python.exe -m src.keypoint.train --data-root data/processed/keypoints/cej --keypoint-type cej --output-dir runs/keypoints/cej
```

### 3. Severity evaluation (ICC)

After inference, severity is computed with `src/severity/bone_loss.py` (paper Eq. 1 + min-max line).

Paper target (test ICC): **0.801**
